# 每月超过60小时加班的加算率

一个月的加班(法定时间外劳动)**超过60小时**时，其**超出部分**的加算工资率
为**50%以上**(《劳动基准法》第37条第1款但书)。

## 60小时以内的部分不变

变为50%的只是超过60小时的部分，60小时以内的部分仍然维持通常加班的加算率
(25%以上)。并不是「每月超过60小时后全部按50%」。

| 加班的区分 | 加算率 |
| --- | --- |
| 60小时以内 | 25%以上 |
| 超过60小时的部分 | 50%以上 |

## 中小企业的缓行期已经结束

这项50%规则对大企业自2010年4月1日起适用，但对中小企业曾有缓行措施。
自**2023年4月1日**起已对中小企业适用，目前无论企业规模如何
都适用相同的规则。
