# 打卡记录不完整时的处理

由于忘记打卡或误操作，上下班或休息的打卡记录有时会不齐全。KIZAMI 对这类情况
采取**保守解释**。

## 采取保守解释的理由

劳动时间需要正确记录"实际工作过的时间"。如果用推测填补缺失打卡的区间并计为劳动时间，
就有可能记录出多于(或少于)实际情况的劳动时间。为了不把没有确证的区间捏造成劳动时间，
KIZAMI 采取**不把缺失的信息计入汇总**的方针。如果与实际劳动时间不符，
请通过更正申请补上正确的打卡记录。

## 主要情形

| 情况 | KIZAMI 的处理 |
| --- | --- |
| 没有下班打卡 | 将该勤务区间从汇总中排除(不计为工作过的时间) |
| 勤务中存在重复的上班打卡 | 使之后重复的上班打卡失效 |
| 未上班状态下的下班打卡 | 使该下班打卡失效 |
| 勤务时间外的休息打卡 | 使该休息打卡失效 |
| 休息中存在重复的休息开始打卡 | 使之后重复的休息开始打卡失效 |
| 没有对应休息开始的休息结束打卡 | 使该休息结束打卡失效 |
| 休息中存在下班打卡 | 视为结束休息后下班 |

这些会显示在月度画面的警告列中。如果与实际劳动时间不同，请从该日的"更正"
提出正确的打卡申请。
