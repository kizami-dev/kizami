# 離職後紀錄的儲存與消除

即使離職，考勤紀錄也不會立即消失。這是因為**法律規定了儲存義務**。

## 兩部法律指向相反的方向

| 法律 | 所要求的內容 |
| --- | --- |
| 《勞動基準法》第109條 | **必須儲存**薪資台帳、出勤簿等紀錄(原則5年。根據附則第143條第2款的過渡措施，暫時為3年) |
| 《個人資料保護法》第22條 | 對於已無使用必要的個人資料，**必須努力不遲延地予以消除** |

對於離職者，這兩者正面衝突。消除紀錄會違反《勞動基準法》，
而繼續保留則違反《個人資料保護法》的努力義務。

既然儲存義務是「必須」(義務)，而消除是「必須努力」(努力義務)，
那麼**在儲存期限屆滿之前予以保留**才是正確的順序。

## 儲存期限的起算日

《勞動基準法》第109條的儲存期限自「最後記載之日」起算。就離職者而言，最後一條考勤紀錄
即為該日。KIZAMI 將**辦理離職處理之日**作為起算日。由於離職處理在最終出勤日之後辦理，
這種處理只可能比實際的起算日**更靠後**，而不會提前，因此不會侵蝕義務期間。

## 期限屆滿後會發生什麼

保留期限屆滿後，管理員即可消除離職者的個人資料。
此時消失的內容與保留的內容如下。

| 對象 | 處理 |
| --- | --- |
| 姓名、電子郵件地址 | 替換為無法識別個人的表述 |
| 密碼、雙重驗證、登入資訊 | 刪除 |
| 通知設定、終端資訊(IP地址、瀏覽器資訊、位置資訊) | 刪除 |
| 考勤紀錄(打卡時刻、彙總結果、已結算月份的數字) | **保留**(因為存在儲存義務) |
| 稽核日誌 | **保留**(不作改動。僅將其中顯示的姓名匿名化) |

也就是說，這並不是「消除紀錄」，而是**從紀錄中去除「這是誰的紀錄」這一資訊**的操作。
由於考勤紀錄的行本身不會消失，過去已結算月份的彙總值在消除前後不會發生變化。

該操作**無法撤銷**。離職後如希望取得本人紀錄的公開，
請在保留期限屆滿之前聯絡公司的視窗。

## 保留期限由公司選擇

採用3年(過渡措施)還是5年(原則)由公司決定。KIZAMI 的預設值為**5年**
—— 因為過渡措施終將結束，屆時若仍維持3年就無法滿足儲存義務。
