# 36協定的上限規制

要安排加班(法定時間外勞動)或休息日勞動，必須事先簽訂並申報36協定(36協定，依據《勞動基準法》第36條簽訂的勞資協定)。
其延長時間設有附帶罰則的上限(《勞動基準法》第36條第4款至第6款)。

## 原則(限度時間)

| 區分 | 上限 |
| --- | --- |
| 每月 | 45小時 |
| 每年 | 360小時 |

## 特別條款(存在臨時性特別情況時)

在需要超過原則上限安排勞動的情況下，以**事先簽訂並申報了附帶特別條款的36協定**為前提，
可以延長至以下上限。若沒有特別條款，則不允許進行此項延長。

| 區分 | 上限 |
| --- | --- |
| 年度加班時間 | 720小時以內 |
| 單月(含休息日勞動) | 不滿100小時 |
| 多月平均(2〜6個月平均，含休息日勞動) | 80小時以內 |
| 可超過每月45小時的次數 | 每年至多6次 |

特別條款終究只是為存在"臨時性特別情況"的月份而設的，
其宗旨並不是允許常態化地按上限滿額安排勞動。
