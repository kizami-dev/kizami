# 36协定的上限规制

要安排加班(法定时间外劳动)或休息日劳动，必须事先签订并申报36协定(36協定，依据《劳动基准法》第36条签订的劳资协定)。
其延长时间设有附带罚则的上限(《劳动基准法》第36条第4款至第6款)。

## 原则(限度时间)

| 区分 | 上限 |
| --- | --- |
| 每月 | 45小时 |
| 每年 | 360小时 |

## 特别条款(存在临时性特别情况时)

在需要超过原则上限安排劳动的情况下，以**事先签订并申报了附带特别条款的36协定**为前提，
可以延长至以下上限。若没有特别条款，则不允许进行此项延长。

| 区分 | 上限 |
| --- | --- |
| 年度加班时间 | 720小时以内 |
| 单月(含休息日劳动) | 不满100小时 |
| 多月平均(2〜6个月平均，含休息日劳动) | 80小时以内 |
| 可超过每月45小时的次数 | 每年至多6次 |

特别条款终究只是为存在"临时性特别情况"的月份而设的，
其宗旨并不是允许常态化地按上限满额安排劳动。
