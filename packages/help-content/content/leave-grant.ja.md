# 年次有給休暇の法定付与日数と時効

雇入れの日から**6か月間継続勤務**し、その間の全労働日の**8割以上出勤**した労働者には、
年次有給休暇が付与されます(労働基準法39条1項)。以後、勤続年数に応じて日数が増えていきます
(同条2項)。

## 勤続年数ごとの付与日数(フルタイムの場合)

| 勤続年数 | 付与日数 |
| --- | --- |
| 6か月 | 10日 |
| 1年6か月 | 11日 |
| 2年6か月 | 12日 |
| 3年6か月 | 14日 |
| 4年6か月 | 16日 |
| 5年6か月 | 18日 |
| 6年6か月以降 | 20日 |

いずれの区分も、対象期間の全労働日の8割以上出勤していることが条件です。

## 週の所定労働日数が少ない場合

週の所定労働日数が少ないパートタイム労働者等には、上記の表とは別に**比例付与**の日数表が
適用されます(労基法39条3項)。フルタイムの表をそのまま当てはめることはできません。

**比例付与の日数計算は現在 KIZAMI の計算対象外です。** 該当する労働者への付与日数は、
比例付与の日数表(労基法39条3項)に基づき管理者が手動で確認・設定してください。

## 時効は2年

付与された年次有給休暇は、**付与日から2年**で時効により消滅します(労基法115条)。前年度分の
未消化が当年度に繰り越されるのはこの2年以内の分だけです。
