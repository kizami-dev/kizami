# 彈性工作時間制的總時長上限

在彈性工作時間制下，不是按每一天，而是以**結算期間(在本設定中為1個月)的合計**
來判斷勞動時間。該期間應當工作的時間上限稱為"総枠"(結算期間總時長上限)。

```
總時長上限 = 每週法定勞動時間 × 該月曆日數 ÷ 7
```

每週法定勞動時間原則上為40小時。作為例外，商業、電影戲劇業、保健衛生業、接待娛樂業中
經常使用勞動者不滿10人的事業場所([特例措置対象事業場](./tenant-special-provision))為44小時。

| 月的天數 | 每週40小時的情況 | 每週44小時的情況 |
| --- | --- | --- |
| 30天 | 171小時25分鐘 | 188小時34分鐘 |
| 31天 | 177小時8分鐘 | 194小時51分鐘 |

實績超出總上限的部分為**加班**，低於總上限的部分為**不足**。在 KIZAMI 的月度畫面中
顯示為"彈性工時收支"。

## 休年假當天的處理

取得年度帶薪休假的當天，視為已工作而計入實績(全天則按約定勞動時間計，半天則按其一半計，
按小時則按該時數計)。不會因為休了帶薪假而使不足增加。
