# 每月超過60小時加班的加算率

一個月的加班(法定時間外勞動)**超過60小時**時，其**超出部分**的加算薪資率
為**50%以上**(《勞動基準法》第37條第1款但書)。

## 60小時以內的部分不變

變為50%的只是超過60小時的部分，60小時以內的部分仍然維持通常加班的加算率
(25%以上)。並不是「每月超過60小時後全部按50%」。

| 加班的區分 | 加算率 |
| --- | --- |
| 60小時以內 | 25%以上 |
| 超過60小時的部分 | 50%以上 |

## 中小企業的緩行期已經結束

這項50%規則對大企業自2010年4月1日起適用，但對中小企業曾有緩行措施。
自**2023年4月1日**起已對中小企業適用，目前無論企業規模如何
都適用相同的規則。
