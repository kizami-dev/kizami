# 深夜劳动(22点至次日5点)的加算

在**下午10点至次日凌晨5点**之间工作的时间视为深夜劳动，除通常工资外，
还属于**25%以上**加算工资的对象(《劳动基准法》第37条第4款)。

## 重叠时合并计算

深夜劳动有时会与加班或休息日劳动同时发生。这种情况下，加算率将**合并计算**。

| 组合 | 加算率参考 |
| --- | --- |
| 仅深夜劳动 | 25%以上 |
| 加班 + 深夜劳动 | 50%以上(25%+25%) |
| 法定休息日劳动 + 深夜劳动 | 60%以上(35%+25%) |

## KIZAMI 的处理范围

KIZAMI 会根据打卡记录，将属于深夜时段(22点至次日5点)的时长区分出来并汇总。
实际加算工资金额的计算与支付，请依据汇总结果在工资计算一侧进行。
