# 打卡更正申請的流程

打卡紀錄本身無法直接改寫。若要新增、訂正或撤銷打卡紀錄，需要作為**更正申請**送出，
只有在獲得核准的結果下才會反映到考勤紀錄中。

## 申請的種類

- **新增**: 對忘記打卡的上下班、休息時間進行新登記的申請
- **訂正**: 變更既有打卡紀錄的時刻或種別的申請
- **撤銷**: 使既有打卡紀錄視為不存在的申請

## 到核准為止的流程

1. 本人(或擁有代理權限的負責人)附上理由送出申請(狀態: 申請中)
2. 擁有核准權限的負責人確認內容，予以核准或駁回
3. 核准後反映到打卡紀錄中，並反映到月度彙總。被駁回的情況下不會反映
4. 處於申請中的期間，本人也可以撤回

對象月份已經結算的情況下，另外需要解除確定的權限才能核准。

## 全部留存在稽核日誌中

申請的送出、核准、駁回、撤回，包括何時由誰執行在內，全部會記錄到稽核日誌中。
核准者與申請者為同一人的情況(自我核准)，該情況也會作為紀錄留存下來。
