# 退職後の記録の保存と消去

退職しても、勤怠の記録がすぐに消えるわけではありません。**法律が保存を義務づけている**ためです。

## 2つの法律が逆を向いている

| 法律 | 求めていること |
| --- | --- |
| 労働基準法109条 | 賃金台帳・出勤簿等の記録を**保存しなければならない**(原則5年。附則143条2項の経過措置により当分の間3年) |
| 個人情報保護法22条 | 利用する必要がなくなった個人データは**遅滞なく消去するよう努めなければならない** |

退職者について、この2つは正面からぶつかります。記録を消せば労働基準法に反し、
残し続ければ個人情報保護法の努力義務に反する、という形です。

保存義務が「しなければならない」(義務)で、消去が「努めなければならない」(努力義務)である
以上、**保存期間が経過するまでは残す**のが正しい順序です。

## 保存期間の起算日

労働基準法109条の保存期間は「最後の記載日」から数えます。退職者の場合、最後の勤怠記録が
その日にあたります。KIZAMI は**退職処理を行った日**を起算日として扱います。退職処理は
最終出勤日以降に行われるため、この扱いは実際の起算日より**後ろ**になることはあっても
前になることはなく、義務期間を割り込みません。

## 期間の経過後に何が起きるか

保持期間が過ぎると、管理者は退職者の個人データを消去できるようになります。
このとき消えるものと残るものは次のとおりです。

| 対象 | 扱い |
| --- | --- |
| 氏名・メールアドレス | 個人を識別できない表記に置き換える |
| パスワード・二要素認証・ログイン情報 | 削除する |
| 通知の設定・端末の情報(IPアドレス・ブラウザ情報・位置情報) | 削除する |
| 勤怠記録(打刻の時刻・集計結果・締めた月の数字) | **残す**(保存義務のため) |
| 監査ログ | **残す**(改変しない。表示される氏名だけが匿名化される) |

つまり「記録を消す」のではなく、**記録から『誰の記録か』を取り除く**操作です。
勤怠記録の行そのものが消えないため、過去に締めた月の集計値は消去の前後で変わりません。

この操作は**取り消せません**。退職後にご自身の記録の開示を希望される場合は、
保持期間が経過する前に会社の窓口へご連絡ください。

## 保持期間は会社が選びます

3年(経過措置)と5年(原則)のどちらを採るかは会社が決めます。KIZAMI の既定は**5年**です
— 経過措置はいつか終了し、そのとき3年のままにしていると保存義務を満たせなくなるためです。
