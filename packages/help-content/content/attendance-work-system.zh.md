# 工作时间制与"时间外"的含义

同样是"一天工作了10小时"，是否构成加班会因所适用的工作时间制而不同。

## 固定工作时间制

设有**每日8小时、每周40小时**的上限，超过的部分当场即成为加班
(《劳动基准法》第32条)。无需等到月末，当天即告确定。

在约定劳动时间为7小时的公司工作了7小时30分钟时，这30分钟虽然超过了约定时间，
但因在每日8小时以内，所以**不属于法定时间外劳动**。无需支付加算工资，
但工作过的部分的工资当然要支付。KIZAMI 中会将其区分显示为"法定时间内加班"。

## 弹性工作时间制

将结算期间(KIZAMI 中为1个月)的**总时长上限(総枠)**与实绩相比较，超出的部分成为加班
(《劳动基准法》第32条之3)。总时长上限由"每周法定劳动时间 × 该月历日数 ÷ 7"确定。

**不存在以日为单位的加班这一概念。** 即使某一天工作了10小时，
只要在当月的总时长上限之内，就不属于加班。由于该制度的宗旨在于由本人决定上下班时刻，
因此采用了不按日设置上限的机制。

也正因如此，适用弹性工作时间制者的月度一览中**不显示加班列**。
准确地说，并非是隐藏不显示，而是当天尚未确定。
月中的预计情况可以通过"弹性工时收支"确认。

## 两种制度下都不变的内容

以下内容无论适用何种工作时间制都同样处理。

| | 内容 |
| --- | --- |
| 深夜劳动 | 22点至次日5点的劳动。加算25%以上(《劳动基准法》第37条第4款) |
| 法定休息日劳动 | 每周1天的法定休息日的劳动。加算35%以上(《劳动基准法》第37条第1款) |
| 休息时间 | 超过6小时为45分钟，超过8小时为60分钟(《劳动基准法》第34条) |
| 年度带薪休假 | 授予天数、每年5天的取得义务(《劳动基准法》第39条) |
