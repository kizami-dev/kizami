# 工作時間制與"時間外"的含義

同樣是"一天工作了10小時"，是否構成加班會因所適用的工作時間制而不同。

## 固定工作時間制

設有**每日8小時、每週40小時**的上限，超過的部分當場即成為加班
(《勞動基準法》第32條)。無需等到月末，當天即告確定。

在約定勞動時間為7小時的公司工作了7小時30分鐘時，這30分鐘雖然超過了約定時間，
但因在每日8小時以內，所以**不屬於法定時間外勞動**。無需支付加算薪資，
但工作過的部分的薪資當然要支付。KIZAMI 中會將其區分顯示為"法定時間內加班"。

## 彈性工作時間制

將結算期間(KIZAMI 中為1個月)的**總時長上限(総枠)**與實績相比較，超出的部分成為加班
(《勞動基準法》第32條之3)。總時長上限由"每週法定勞動時間 × 該月曆日數 ÷ 7"確定。

**不存在以日為單位的加班這一概念。** 即使某一天工作了10小時，
只要在當月的總時長上限之內，就不屬於加班。由於該制度的宗旨在於由本人決定上下班時刻，
因此採用了不按日設定上限的機制。

也正因如此，適用彈性工作時間制者的月度一覽中**不顯示加班列**。
準確地說，並非是隱藏不顯示，而是當天尚未確定。
月中的預計情況可以透過"彈性工時收支"確認。

## 兩種制度下都不變的內容

以下內容無論適用何種工作時間制都同樣處理。

| | 內容 |
| --- | --- |
| 深夜勞動 | 22點至次日5點的勞動。加算25%以上(《勞動基準法》第37條第4款) |
| 法定休息日勞動 | 每週1天的法定休息日的勞動。加算35%以上(《勞動基準法》第37條第1款) |
| 休息時間 | 超過6小時為45分鐘，超過8小時為60分鐘(《勞動基準法》第34條) |
| 年度帶薪休假 | 授予天數、每年5天的取得義務(《勞動基準法》第39條) |
