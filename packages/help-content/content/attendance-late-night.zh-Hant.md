# 深夜勞動(22點至次日5點)的加算

在**下午10點至次日凌晨5點**之間工作的時間視為深夜勞動，除通常薪資外，
還屬於**25%以上**加算薪資的對象(《勞動基準法》第37條第4款)。

## 重疊時合併計算

深夜勞動有時會與加班或休息日勞動同時發生。這種情況下，加算率將**合併計算**。

| 組合 | 加算率參考 |
| --- | --- |
| 僅深夜勞動 | 25%以上 |
| 加班 + 深夜勞動 | 50%以上(25%+25%) |
| 法定休息日勞動 + 深夜勞動 | 60%以上(35%+25%) |

## KIZAMI 的處理範圍

KIZAMI 會根據打卡紀錄，將屬於深夜時段(22點至次日5點)的時長區分出來並彙總。
實際加算薪資金額的計算與支付，請依據彙總結果在薪資計算一側進行。
