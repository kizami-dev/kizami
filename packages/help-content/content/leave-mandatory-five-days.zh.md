# 每年5天的取得义务

被授予每年10天以上年度带薪休假的人，需要在**授予日起1年以内取得5天**。
这既是劳动者的权利，同时也是课予公司的义务。

## 计算方式需注意

| 取得的单位 | 是否计入5天 |
| --- | --- |
| 全天 | 按1.0天计算 |
| 半天(上午・下午) | **按0.5天计算** |
| 按小时 | **不计入** |

按小时取得的年度带薪休假，不被认可为满足这5天义务的取得方式。
即使按小时取得了40小时，义务的履行仍然是0天。要满足该义务，
需要以全天或半天的方式取得。

## 期限

期限是「授予日起1年后」。由于授予日因人而异(以入职日为基准的情况下)，
期限也因人而异。可以在 KIZAMI 的带薪休假画面确认自己的期限和剩余天数。

临近期限时会收到通知(90天前・30天前)。
