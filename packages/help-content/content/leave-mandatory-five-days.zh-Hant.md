# 每年5天的取得義務

被授予每年10天以上年度帶薪休假的人，需要在**授予日起1年以內取得5天**。
這既是勞動者的權利，同時也是課予公司的義務。

## 計算方式需注意

| 取得的單位 | 是否計入5天 |
| --- | --- |
| 全天 | 按1.0天計算 |
| 半天(上午・下午) | **按0.5天計算** |
| 按小時 | **不計入** |

按小時取得的年度帶薪休假，不被認可為滿足這5天義務的取得方式。
即使按小時取得了40小時，義務的履行仍然是0天。要滿足該義務，
需要以全天或半天的方式取得。

## 期限

期限是「授予日起1年後」。由於授予日因人而異(以入職日為基準的情況下)，
期限也因人而異。可以在 KIZAMI 的帶薪休假畫面確認自己的期限和剩餘天數。

臨近期限時會收到通知(90天前・30天前)。
