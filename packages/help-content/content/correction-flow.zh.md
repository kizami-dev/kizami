# 打卡更正申请的流程

打卡记录本身无法直接改写。若要新增、订正或撤销打卡记录，需要作为**更正申请**提交，
只有在获得批准的结果下才会反映到考勤记录中。

## 申请的种类

- **新增**: 对忘记打卡的上下班、休息时间进行新登记的申请
- **订正**: 变更既有打卡记录的时刻或种别的申请
- **撤销**: 使既有打卡记录视为不存在的申请

## 到批准为止的流程

1. 本人(或拥有代理权限的负责人)附上理由提交申请(状态: 申请中)
2. 拥有批准权限的负责人确认内容，予以批准或驳回
3. 批准后反映到打卡记录中，并反映到月度汇总。被驳回的情况下不会反映
4. 处于申请中的期间，本人也可以撤回

对象月份已经结算的情况下，另外需要解除确定的权限才能批准。

## 全部留存在审计日志中

申请的提交、批准、驳回、撤回，包括何时由谁执行在内，全部会记录到审计日志中。
批准者与申请者为同一人的情况(自我批准)，该情况也会作为记录留存下来。
