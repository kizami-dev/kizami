# 근태 기록이 불완전할 때의 취급

기록 누락이나 오조작으로 출퇴근이나 휴게 기록이 갖추어지지 않는 경우가 있습니다. KIZAMI는 이러한 경우를
**보수적으로 해석**합니다.

## 보수적으로 해석하는 이유

근로시간은 '실제로 근로한 시간'을 올바르게 기록해야 합니다. 기록이 빠진 구간을
추측으로 메워 근로시간으로 계산해 버리면, 실태보다 많은(또는 적은) 근로시간을
기록하게 될 수 있습니다. KIZAMI는 확증이 없는 구간을 근로시간으로 지어내지 않기 위해
**부족한 정보는 집계에 포함하지 않는** 방침을 취하고 있습니다. 실제 근로시간과 어긋나는 경우에는
정정 신청으로 올바른 기록을 보완해 주십시오.

## 주요 패턴

| 상황 | KIZAMI의 취급 |
| --- | --- |
| 퇴근 기록이 없음 | 해당 근무 구간을 집계에서 제외(근로한 시간으로 세지 않음) |
| 근무 중에 중복된 출근 기록이 있음 | 나중의 중복된 출근 기록을 무효로 함 |
| 출근하지 않은 상태에서의 퇴근 기록 | 해당 퇴근 기록을 무효로 함 |
| 근무 외의 휴게 기록 | 해당 휴게 기록을 무효로 함 |
| 휴게 중에 중복된 휴게 시작 기록이 있음 | 나중의 중복된 휴게 시작 기록을 무효로 함 |
| 대응하는 휴게 시작이 없는 휴게 종료 기록 | 해당 휴게 종료 기록을 무효로 함 |
| 휴게 중에 퇴근 기록이 있음 | 휴게를 마치고 퇴근한 것으로 취급 |

이들은 월별 화면의 경고 열에 표시됩니다. 실제 근로시간과 다른 경우에는 그날의 '정정'에서
올바른 기록을 신청해 주십시오.
