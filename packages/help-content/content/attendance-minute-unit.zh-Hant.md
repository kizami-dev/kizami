# 勞動時間的尾數處理(以1分鐘為單位)

勞動時間原則上應以**1分鐘為單位**計算每日的實績。像"不滿15分鐘捨去""不滿30分鐘捨去"
那樣，把時間取整得短於實際工作時間從而減少薪資的做法，有可能被認定為違反《勞動基準法》
第24條(薪資全額支付)或第37條(加算薪資的支付)。

## 唯一的例外: 對1個月合計的尾數處理

雖然不能對每日的勞動時間本身取整，但僅限於**1個月的加班(法定時間外勞動)、休息日勞動、
深夜勞動的合計**產生不滿1小時的尾數時，允許採取不滿30分鐘捨去、30分鐘以上進位的處理
(昭63.3.14基発150號，即1988年3月14日基發第150號通達)。

| 對象 | 尾數處理 |
| --- | --- |
| 每日的勞動時間 | 不可捨去(以1分鐘為單位計算) |
| 1個月的加班等合計 | 可以不滿30分鐘捨去、30分鐘以上進位 |

人們常誤以為"每日的打卡紀錄可以取整"，但獲得認可的只有針對月度合計的處理。
