# 근태 기록 정정 신청의 흐름

근태 기록(출퇴근·휴게 기록) 자체를 직접 고쳐 쓸 수는 없습니다. 근태 기록을 추가·정정·취소하려면
**정정 신청**으로 제출해야 하며, 승인된 결과로서만 근태 기록에 반영됩니다.

## 신청의 종류

- **추가**: 기록하지 못한 출퇴근·휴게를 새로 등록하는 신청
- **정정**: 기존 기록의 시각이나 종류를 변경하는 신청
- **취소**: 기존 기록을 없던 것으로 하는 신청

## 승인까지의 흐름

1. 본인(또는 대리 권한을 가진 담당자)이 사유를 붙여 신청한다(상태: 신청 중)
2. 승인 권한을 가진 담당자가 내용을 확인하고 승인 또는 반려한다
3. 승인되면 근태 기록에 반영되고 월별 집계에도 반영된다. 반려된 경우에는 반영되지 않는다
4. 신청 중인 동안에는 본인이 철회할 수도 있다

대상 월이 이미 마감된 경우, 승인하려면 마감 해제 권한이 별도로 필요합니다.

## 모두 감사 로그에 남는다

신청의 제출·승인·반려·철회는 언제·누가 했는지를 포함하여 모두 감사 로그에 기록됩니다.
승인자와 신청자가 동일 인물인 경우(자기 승인)에도 그러한 사실이 기록으로 남습니다.
