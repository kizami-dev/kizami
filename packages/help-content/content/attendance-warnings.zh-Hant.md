# 打卡紀錄不完整時的處理

由於忘記打卡或誤操作，上下班或休息的打卡紀錄有時會不齊全。KIZAMI 對這類情況
採取**保守解釋**。

## 採取保守解釋的理由

勞動時間需要正確紀錄"實際工作過的時間"。如果用推測填補缺失打卡的區間並計為勞動時間，
就有可能記錄出多於(或少於)實際情況的勞動時間。為了不把沒有確證的區間捏造成勞動時間，
KIZAMI 採取**不把缺失的資訊計入彙總**的方針。如果與實際勞動時間不符，
請透過更正申請補上正確的打卡紀錄。

## 主要情形

| 情況 | KIZAMI 的處理 |
| --- | --- |
| 沒有下班打卡 | 將該勤務區間從彙總中排除(不計為工作過的時間) |
| 勤務中存在重複的上班打卡 | 使之後重複的上班打卡失效 |
| 未上班狀態下的下班打卡 | 使該下班打卡失效 |
| 勤務時間外的休息打卡 | 使該休息打卡失效 |
| 休息中存在重複的休息開始打卡 | 使之後重複的休息開始打卡失效 |
| 沒有對應休息開始的休息結束打卡 | 使該休息結束打卡失效 |
| 休息中存在下班打卡 | 視為結束休息後下班 |

這些會顯示在月度畫面的警告列中。如果與實際勞動時間不同，請從該日的"更正"
提出正確的打卡申請。
