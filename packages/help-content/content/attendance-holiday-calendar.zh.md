# 约定休息日日历

约定休息日日历是确定**哪些日子是约定工作日**的设置。在 KIZAMI 中，
它用于计算总劳动时间以"约定天数 × 标准时间"确定的弹性工作制度
([总劳动时间的确定方法](./attendance-flex-contract))的约定工作日数。
对总劳动时间为"法定上限"的制度没有影响。

## 可以设置的内容

| 项目 | 内容 | 默认 |
| --- | --- | --- |
| 约定休息日的星期 | 每周休息的星期 | 星期六、星期日 |
| 国民节假日 | 是否将节假日(含调休假日、国民休息日)作为约定休息日 | 是 |
| 追加为休息日的日期 | 年末年初、夏季休业等个别休息的日子 | 无 |
| 从休息日中排除的日期 | 节假日但营业的日子等作为约定工作日的日子 | 无 |

与考勤规则的其他设置一样，以**带适用开始日的版本**保存。新版本只能从今天以后的日期
添加，过去月份的计算不会改变。从未保存过日历时，按默认(周六日、节假日)计算。

## 与法定休息日的关系

法定休息日(《劳动基准法》第35条规定的每周1天或4周4天的休息日，[法定休息日与约定休息日的区别](./attendance-legal-holiday))是
约定休息日的一部分。计算约定工作日数时，法定休息日**无论本日历如何设置都视为休息日**
(即使忘记加入星期，或指定为排除的日期，也不会成为约定工作日)。

反之，本日历中的约定休息日不会被视为法定休息日。休息日劳动(35%以上加算)的对象
仅限于考勤规则中设置的法定休息日的劳动。

## 国民节假日数据

节假日根据内阁府公开的"国民节假日"一览表判定，该数据随 KIZAMI 一同提供。
下一年的春分日、秋分日每年2月左右确定，因此随附数据每年更新1次。
计算随附数据中没有的年份的月份时，将节假日计为约定工作日并显示警告。
