# 离职后记录的保存与消除

即使离职，考勤记录也不会立即消失。这是因为**法律规定了保存义务**。

## 两部法律指向相反的方向

| 法律 | 所要求的内容 |
| --- | --- |
| 《劳动基准法》第109条 | **必须保存**工资台账、出勤簿等记录(原则5年。根据附则第143条第2款的过渡措施，暂时为3年) |
| 《个人信息保护法》第22条 | 对于已无使用必要的个人数据，**必须努力不迟延地予以消除** |

对于离职者，这两者正面冲突。消除记录会违反《劳动基准法》，
而继续保留则违反《个人信息保护法》的努力义务。

既然保存义务是「必须」(义务)，而消除是「必须努力」(努力义务)，
那么**在保存期限届满之前予以保留**才是正确的顺序。

## 保存期限的起算日

《劳动基准法》第109条的保存期限自「最后记载之日」起算。就离职者而言，最后一条考勤记录
即为该日。KIZAMI 将**办理离职处理之日**作为起算日。由于离职处理在最终出勤日之后办理，
这种处理只可能比实际的起算日**更靠后**，而不会提前，因此不会侵蚀义务期间。

## 期限届满后会发生什么

保留期限届满后，管理员即可消除离职者的个人数据。
此时消失的内容与保留的内容如下。

| 对象 | 处理 |
| --- | --- |
| 姓名、电子邮件地址 | 替换为无法识别个人的表述 |
| 密码、双因素认证、登录信息 | 删除 |
| 通知设置、终端信息(IP地址、浏览器信息、位置信息) | 删除 |
| 考勤记录(打卡时刻、汇总结果、已结算月份的数字) | **保留**(因为存在保存义务) |
| 审计日志 | **保留**(不作改动。仅将其中显示的姓名匿名化) |

也就是说，这并不是「消除记录」，而是**从记录中去除「这是谁的记录」这一信息**的操作。
由于考勤记录的行本身不会消失，过去已结算月份的汇总值在消除前后不会发生变化。

该操作**无法撤销**。离职后如希望获取本人记录的公开，
请在保留期限届满之前联系公司的窗口。

## 保留期限由公司选择

采用3年(过渡措施)还是5年(原则)由公司决定。KIZAMI 的默认值为**5年**
—— 因为过渡措施终将结束，届时若仍维持3年就无法满足保存义务。
