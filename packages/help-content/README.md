# @kizami/help-content

コンテキストヘルプ文言の単一ソース(要件 §10)。

- 1エントリ=1ファイル、`content/<key>.<lang>.md`
- frontmatter の `summary` がUIツールチップ用(1〜2文)、本文がドキュメント用の詳細
- ビルドで型付き辞書を生成し、キーの参照ミス・訳文欠落はCIエラーにする(ビルドスクリプトは v0.2 で実装)
- VitePress は同じ Markdown をページとして取り込む

付与の目安: 影響が画面の外に及ぶ操作(締め・承認・権限割当・自動控除ルール)と、
法制度に由来する表示(清算期間の総枠・法定休日・年5日義務・36協定の閾値)。
自明な操作(出勤ボタン等)には付けない。
