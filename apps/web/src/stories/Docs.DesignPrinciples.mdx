# デザイン原則(要約)

原典は
[`docs/design/ui-direction.md`](https://github.com/sasagar/kizami/blob/main/docs/design/ui-direction.md)。
このページは要点の要約に留める(**文章の重複メンテを避けるため**、詳細な理由づけ・全ルールは
必ず原典を参照すること)。

## コンセプト: 印刷所の刻印

KIZAMI の世界観は**印刷プロセス**。打刻=スタンプ(刻印)、CMYK=プロセスインキ、打刻列=トンボ
(見当合わせマーク)、月次集計=インキ濃度。「毎日押すことが楽しい」の中心は打刻ボタンの刻印演出
だけに集中させ、それ以外(締め/承認系など)は明瞭優先で静かに保つ。

## 色の役割規律

- インキ原色(`--k-cyan`/`--k-magenta`/`--k-yellow`)は**塗り・大型要素専用**
- テキストには AA を満たす ink 変種(`--k-*-ink`)を使う
- `--k-yellow` はテキスト使用禁止(コントラスト不足)
- 意味づけ: 出勤=C、休憩=Y、退勤=M、地とテキスト=K。**常にラベル・アイコンを併記**し、
  色のみに意味を持たせない

詳細な値・ダーク対応の設計は [Tokens/Colors](?path=/story/tokens-colors--palette) を参照
(tokens.css の実値をそのまま反映)。

## 「意味色は状態のみ」

CMYK の3色は打刻の3操作(出勤/休憩/退勤)にしか使わない。締めバッジ・警告・危険操作など他の
状態表現は、この規律の**外側**にある独立した意味色(例: 確定済み=C、修正あり=Y、締めの解除=M)
として個別に定義する — 打刻の色と混ざらないよう画面ごとに閉じたスコープで使う。

## 演出は一点豪華、それ以外は静か

- シグネチャ演出は打刻スタンプの「刻まれる」アニメーション(約300ms)の1箇所に集中
- ボタン浮遊・グラデーション・カード多用はしない
- 番号付きマーカー等の「構造の装飾」は使わない(トンボ列だけは実時系列という情報を運ぶため例外)
- `prefers-reduced-motion` では即時表示に置き換える

## ガイド・ヘルプの方針: 出所を必ず区別する

表示するすべての説明に **法令 / KIZAMIの仕様 / 自社の規定** のいずれかのラベルを付ける。混ぜると、
法定要件を社内ルールだと誤認して緩めたり、その逆をしたりする(コンプライアンス製品として
最も危険な失敗)。実装は [Patterns/HelpTip & Dialog](?path=/story/patterns-helptip---dialog--contextual-help)
を参照。

## 品質フロア

- モバイル〜デスクトップのレスポンシブ
- キーボードフォーカス可視、`prefers-reduced-motion` 尊重
- テキストコントラストは AA(4.5:1)以上(ink 変種の使用を徹底)
- 文言は動詞ラベルで統一(i18n キー化) — このカタログ自体もツールバーの言語切り替えで
  4言語(ja/en/ko/zh)の検品ができる
